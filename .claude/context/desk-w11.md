## Builds run on the VPS, never in WSL (ABSOLUTE RULE on DESK_W11, every project)
Never run docker, `dotnet`, `npm`/`cargo`/`pip` builds or any CPU-heavy compile locally: a WSL2 docker build stalls Hyper-V's vSwitch ~2.5 s and freezes every Windows socket — the user feels it as game lag (measured 2026-10-09, two capture-wide silences at the publish steps). Use `~/.dotfiles/scripts/rbuild PROJECT_DIR -- COMMAND`: it syncs the tree to VPS_PROD `/dev/shm/rbuild/<name>` (RAM — the VPS disk does ~70 sync IOPS; a 917 MB `docker pull` extraction stalled every service for 35 min on 2026-10-09), runs it under `nice` with docker capped at half the cores (`DOCKER_CPUS`), refuses to start at io pressure > 10 %, copies `build/out` back (`-b PATH` for other results). A build that needs a NEW docker image pulls it on the VPS disk: pull by hand when nobody needs the VPS, never inside a routine build. `install.sh` (nix) is the one exception until distributed nix builds exist.

## Deploying this machine from a Windows-side session (`wsl.exe`)
Launch `install.sh` detached (`setsid -f … < /dev/null`) or `sudo` reads a dead pseudo-TTY and times out after 5 min without ever showing the askpass. The askpass is a native Windows box through interop (`sudoAskpassWindowsNative`, `system/security/windows-password-box.ps1`): WSLg paints only the first Linux window of a boot, every later one is an empty surface (measured with AkuWM stopped); zenity is only the fallback when interop is down. AkuWM 0.2.6 centres WSLg windows on the pointer monitor instead of tiling them (rule `r-wslg`). If `.exe` calls from WSL die with "cannot execute binary file", binfmt lost `WSLInterop` — from PowerShell: `wsl.exe -d NixOS -u root -- sh -c "echo ':WSLInterop:M::MZ::/init:PF' > /proc/sys/fs/binfmt_misc/register"` (declarative since `wsl.interop.register = true`). Runbook: `~/.dotfiles/docs/akunito/infrastructure/desk-w11-wsl.md`, "The restart loop of 2026-10-02". Deploy flags here: `install.sh ~/.dotfiles DESK_W11 -s -d` (no `-h`: the WSL hardware config is regenerated each run).
